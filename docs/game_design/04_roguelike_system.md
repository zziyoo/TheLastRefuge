# 《最后避难所》肉鸽构筑系统

# 1. 目标

肉鸽系统负责保证：

> 同一个 60 天流程，每次都可以发展成不同的基地。

---

# 2. 肉鸽层级

四层：

```text
世界规则
↓
发展路线
↓
普通强化
↓
传奇遗物
```

---

# 3. 世界规则

开局随机获得 1～2 个世界规则。

例：

### 极寒世界

```text
寒冷天气概率增加
食物需求增加
农业下降
燃料重要性提高
```

### 丰饶世界

```text
资源增加
探索资源增加
但大型灾害概率提高
```

### 污染世界

```text
疾病概率增加
净水系统重要
医疗强化效果提高
```

---

# 4. 初始发展路线

第 10～20 天之间确定主要路线。

推荐：

```text
工业
农业
探索
科研
外交
```

每条路线不是职业锁定。

而是：

> 获得不同强化池的出现概率。

---

# 5. 普通强化

每次提供：

> 3 选 1。

例如：

```text
高效农业
食物生产 +15%

精密制造
零件生产 +20%

野外求生
探索消耗时间 -1
```

---

# 6. 强化出现频率

建议：

```text
每 3～5 天：
一次普通肉鸽选择

重大节点：
传奇选择
```

整个 60 天：

> 约 15～20 次普通选择。

---

# 7. 传奇遗物

每局约：

> 5～8 个。

遗物通常具有：

```text
强力正面
+
明确代价
```

例如：

### 自动化核心

```text
工业生产 +15%
电力消耗 +20%
```

### 冷冻仓储

```text
食物腐败 -80%
能源消耗 +15%
```

### 军用医疗箱

```text
治疗效率 +50%

药品生产 -20%
```

---

# 8. 遗物联动

遗物必须支持组合。

例如：

```text
自动化核心
+
大型能源站
```

触发：

```text
自动化核心负面电力消耗降低
```

又例如：

```text
冷冻仓储
+
太阳能
```

触发：

```text
白天自动储存额外能源
```

---

# 9. 构筑标签

系统应该根据玩家拥有的内容自动计算构筑标签。

例如：

```text
工业 ≥ 70
探索 ≥ 20

→ 机械探险
```

或者：

```text
农业 ≥ 70
生态相关遗物 ≥ 3

→ 绿色文明
```

构筑标签用于：

```text
日志
结局
成就
事件
局外解锁
```

---

# 10. 构筑不能无限叠加

必须存在容量限制。

例如：

```text
普通强化槽：12
传奇遗物槽：8
```

超过限制后：

> 玩家必须舍弃旧强化。

这样会产生真正的取舍。

---

# 11. 稀有度

建议：

```text
普通
稀有
史诗
传奇
```

但稀有度不是简单数值强弱。

传奇效果应该更加特殊。

---

# 12. 肉鸽选择必须与局势相关

系统不能纯随机。

例如：

```text
当前食物库存极低
```

则三选一可能更容易出现农业相关选项。

但不能完全保证出现。

目标：

> 让玩家能够根据局势寻找解决方案，而不是完全被 RNG 杀死。

---

# 13. 保护机制

连续多次没有获得与核心构筑相关的内容后：

> 提高相关标签内容出现概率。

避免：

> 玩家因为一次随机结果直接进入无解状态。

---

# 14. 肉鸽奖励不应只是百分比

奖励类型应该包括：

```text
数值强化
新建筑
新工作方式
新资源转换
新事件
新探索能力
新角色能力
特殊规则
```

例如：

```text
“猎人制度”

允许：

没有农田时，也可以依靠野外食物维持人口。
```

这比：

> 食物 +10%

更加有趣。
