# 《最后避难所》局外成长与重玩系统

# 1. 基本原则

局外成长不能严重破坏公平性。

不推荐：

```text
永久攻击 +100%
永久食物 +100%
永久生命 +100%
```

因为这会让后续周目越来越简单。

推荐：

> 解锁新内容、新路线、新角色、新规则。

---

# 2. 局外解锁类型

```text
新角色
新职业
新特性
新遗物
新事件
新地点
新世界规则
新派系
新终局
新起始条件
```

---

# 3. 解锁条件

示例：

| 条件      | 解锁    |
| ------- | ----- |
| 存活 20 天 | 新事件   |
| 存活 40 天 | 新遗物   |
| 完成第一次终局 | 新角色   |
| 完成工业流   | 新工业遗物 |
| 完成探索流   | 新探索地点 |
| 完成派系任务  | 新派系   |
| 触发隐藏事件  | 新世界规则 |

---

# 4. 周目难度

通关后可以增加：

```text
难度等级
```

难度不主要通过：

> 所有敌人 +50%

实现。

而是加入额外规则。

例如：

### 难度 II

```text
灾难频率提高
```

### 难度 III

```text
建筑维护增加
```

### 难度 IV

```text
人员死亡风险提高
```

### 难度 V

```text
终局资源减少
```

---

# 5. 新游戏模式

当核心玩法成熟以后，可以加入：

```text
标准模式
极寒模式
人口模式
探索模式
工业模式
无派系模式
极限模式
```

这些都是改变玩法，而不仅仅改变数值。

---

# 6. 每局结算档案

每局结束保存：

```text
生存天数
最终人口
死亡人数
生产总量
探索次数
科技数量
遗物数量
派系关系
重大事件
最终结局
构筑标签
```

---

# 7. 文明档案

玩家可以回顾历史周目。

例如：

```text
周目 #17

名称：
新曙光

生存：
60天

人口：
17 → 12

流派：
工业文明

关键人物：
王
李
陈

重大事件：
矿洞事故
北方战争
太阳风暴
方舟事故

结局：
部分撤离
```

这会增强长期成就感。

---

# 8. 隐藏内容

隐藏内容可以由多个条件组合产生。

例如：

```text
至少拥有 3 名研究员
+
完成地下实验室
+
未加入军方
+
拥有病毒研究

→ 隐藏实验室事件
```

最终：

> 解锁隐藏终局。

---

# 9. 防止重复周目

每次开局至少随机：

```text
世界规则
起始位置
初始角色
角色特性
资源分布
事件池
科技池
遗物池
派系状态
```

因此 2 次完整周目不应该完全相同。

---

# 10. 长期目标

玩家长期目标不是：

> “把数字堆大。”

而是：

```text
解锁
尝试
构筑
实验
发现
完成特殊结局
```

最终游戏应形成：

> “我还没见过这个事件/角色/遗物。”

而不是：

> “我已经把数字刷满了。”
