# 《最后避难所》核心游戏设计

## 1. 项目定位

《最后避难所》是一款单机、手机端、文字与轻量 UI 为主的长期生存经营游戏。

核心体验：

> 生存压力 + 基地经营 + 人员管理 + 随机事件 + 探索 + 肉鸽构筑 + 多结局

主要参考方向：

| 作品                  | 借鉴内容          |
| ------------------- | ------------- |
| 缺氧                  | 系统之间的连锁影响、生产链 |
| 饥荒                  | 生存压力、天气、资源周期  |
| 环世界                 | 人物、关系、随机故事    |
| FTL                 | 风险事件、选择、资源取舍  |
| This War of Mine    | 生存决策、人员状态     |
| Roguelike/Roguelite | 随机路线、构筑、局外解锁  |

不复制上述作品的具体内容、UI、角色或数值。

---

# 2. 核心设计原则

## 2.1 玩家管理的是“社会”，而不是单纯资源

资源只是手段。

真正需要管理的是：

```text
人口
生产
环境
人员关系
科技
派系
探索
风险
终局目标
```

---

## 2.2 每个系统都应该能够影响其他系统

禁止大量“孤立数值”。

错误示例：

```text
建造农场
→ 食物 +20
```

推荐：

```text
建造农场
→ 食物生产增加
→ 占用土地
→ 消耗水
→ 需要人手
→ 产生稳定食物
→ 降低饥饿压力
→ 提高人口规模承载能力
```

系统之间应形成循环。

---

# 3. 一局游戏结构

完整周目：

> 60 游戏日

建议现实游玩时间：

> 约 20～40 小时。

不要求一次完成。

游戏必须支持：

> 随时保存、退出、继续。

---

# 4. 四阶段

| 阶段 |    天数 | 核心问题     |
| -- | ----: | -------- |
| 前期 |  1～15 | 怎么活下来    |
| 中期 | 16～30 | 我要发展成什么  |
| 后期 | 31～48 | 如何维持这个社会 |
| 终局 | 49～60 | 谁能活到最后   |

---

# 5. 核心循环

```text
查看基地状态
↓
安排人员
↓
调整生产
↓
选择探索/研究/建设
↓
推进时间
↓
发生事件
↓
处理事件
↓
资源结算
↓
人物状态变化
↓
获得奖励或负面影响
↓
进入下一时间段
```

# 8. 肉鸽结构

肉鸽不是单纯“增加敌人”。

主要随机来源：

```text
随机世界
随机灾难
随机角色
随机角色特性
随机科技
随机遗物
随机事件
随机派系关系
随机探索地点
随机终局条件
```

玩家每局只接触其中一部分内容。

---

# 9. 终局目标

游戏默认存在：

> 方舟计划

但玩家不一定必须完成方舟。

可出现：

```text
成功撤离
部分撤离
建立永久基地
加入其他文明
基地毁灭
隐藏结局
```

终局应该受到此前 60 天行为影响。

---

# 10. 最大设计目标

每一局游戏都应该让玩家产生：

> “这是我这一局独有的故事。”

而不是：

> “我又重复了一遍上一局。”

因此必须强调：

```text
随机
+
玩家决策
+
系统联动
+
长期后果
```
