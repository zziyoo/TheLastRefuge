7. 事件生成限制

同一类型事件不能在短时间无限重复。

推荐：

同事件：
至少间隔 8 天

同事件链：
不能并行超过 3 条

同类型危机：
3 天内最多 1 个
8. 事件救济机制

如果玩家处于：

极低食物
极低水
人口极少
连续重大灾难

降低“致死型”随机事件权重。

但不完全禁止。

目的是：

防止 RNG 造成不可逆连杀。

9. 事件必须记录“记忆”

每个重要事件写入：

EventHistory

包括：

事件 ID
发生日期
参与人物
选择
结果
相关派系
获得奖励
后续事件 ID

这样终局档案能够回顾整个故事。

10. 事件和肉鸽联动

例如：

拥有：

野外求生

则：

探索事件中：
额外获得安全选项。

拥有：

自动化核心

则：

设备故障类事件：
拥有特殊解决选项。

拥有：

古代数据库

则：

遗迹事件：
增加隐藏选项。

肉鸽不是只改数字。

应该尽量：

改变事件本身的可能性。
