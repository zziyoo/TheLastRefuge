# 《最后避难所》基地、资源与建筑系统

# 1. 基地设计

基地不是自由 3D 地图。

采用：

> “区域 + 建筑”的文字经营结构。

示例：

```text
生活区
生产区
农业区
能源区
医疗区
研究区
仓储区
防御区
```

每个区域包含若干建筑。

# 4. 食物系统

食物至少分为：

```text
野外食物
普通食物
加工食物
高级食物
```

不同食物影响：

```text
饱食度
健康
精神
工作效率
```

---

# 5. 食物腐败

食物不是永久保存。

基础规则：

```text
普通食物：
容易腐败

加工食物：
较慢

冷藏食物：
非常慢
```

建立冷藏设施后：

> 食物损耗明显下降。

---

# 6. 水系统

水来源：

```text
自然水源
雨水
井
净水器
大型净水站
```

污染会造成：

```text
疾病
医疗消耗
工作效率下降
```

因此：

> 水不是单纯资源，而是环境系统的一部分。

---

# 7. 能源系统

能源来源：

```text
木材炉
燃油发电机
太阳能
风力
大型能源站
核能源
```

能源不足会造成：

```text
冷藏停止
医疗设备停止
研究停止
自动工厂停止
通讯停止
```

最终产生连锁反应。

# 9. 建筑升级

每个核心建筑 1～3 级。

示例：

```text
农场 Lv1
食物 +10

农场 Lv2
食物 +18

农场 Lv3
食物 +30
解锁高级作物
```

升级必须有代价：

```text
材料
时间
电力
维护
```

---

# 10. 建筑维护

建筑不是永久有效。

拥有：

```text
耐久
维护需求
故障率
```

例如：

```text
发电机
耐久：72/100

低于 30：
故障率明显增加

低于 10：
可能停机
```

---

# 11. 基地空间

基地拥有有限空间。

因此玩家必须选择：

```text
扩大农业
还是扩大工业

建设仓库
还是建设住房

防御设施
还是研究设施
```

空间本身就是一种资源。

---

# 12. 基地自动化

满足特定条件后解锁自动化。

例如：

```text
智能仓储
自动生产
自动维修
自动农业
自动人员分配
```

自动化本身也是科技/肉鸽构筑的一部分。

---

# 13. 系统联动示例

完整链条：

```text
农场
↓
消耗水、电、人力
↓
生产食物
↓
食物供给人口
↓
人口增长
↓
住房压力增加
↓
需要更多住房
↓
住房增加木材和金属消耗
↓
工业压力增加
```

基地系统必须尽量形成这种循环。
