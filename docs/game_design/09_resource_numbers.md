# 《最后避难所》资源数值规格

## 1. 数值设计目标

本文件定义 V1 的资源系统基础数值。

设计目标：

1. 前期资源紧张，但不应该因为一次普通失误直接必死。
2. 中期允许玩家建立稳定生产链。
3. 后期生产能力明显增强，但消耗同步提高。
4. 终局重点从“持续生产”转向“消耗库存”。
5. 数值必须允许不同肉鸽构筑形成明显差异。
6. 所有数值均为 V1 基准，必须数据驱动。

# 3. 食物

## 基础单位

建议：

> 1 名正常成年人每天基础消耗 2 食物。

因此：

```text
4 人：
8 / 天

8 人：
16 / 天

12 人：
24 / 天

20 人：
40 / 天
```

这使人口增长天然产生压力。

---

## 食物状态

```text
充足
正常
紧张
短缺
断粮
```

建议按照：

```text
库存 / 预计未来 3 天消耗
```

计算警告。

例如：

```text
库存 60
每天消耗 20

预计余量：3 天
```

界面显示：

> 食物：60 / 未来 3 天

---

# 4. 食物类型

## 野外食物

基础：

```text
获得量：3～8
腐败速度：高
健康效果：0
```

## 普通食物

```text
基础价值：1
腐败速度：中
```

## 加工食物

```text
生产：
原料 2 → 食物 4

腐败速度：低
幸福度：+1
```

## 高级食物

```text
生产：
多个基础资源 → 食物 5～6

效果：
压力 -2
健康 +1
```

---

# 5. 水

## 基础消耗

正常角色：

> 2 水 / 天

因此：

```text
4 人：8 / 天
8 人：16 / 天
12 人：24 / 天
20 人：40 / 天
```

极端天气、疾病和高温会增加消耗。

---

# 6. 木材

主要用途：

```text
住房
仓库
基础工具
农业设施
燃料
维修
```

前期获取速度：

> 8～15 / 人日

中期：

> 15～25 / 人日

后期：

> 25～40 / 人日

具体受角色能力、建筑和肉鸽影响。

---

# 7. 石材

主要用途：

```text
基础建筑
墙体
高级住房
防御
道路
```

前期：

> 4～8 / 人日

中期：

> 8～15 / 人日

---

# 8. 铁

铁是第一个重要工业资源。

来源：

```text
矿洞
废墟
贸易
探索
```

基础采矿：

> 4～8 铁 / 人日

优秀矿工：

> 8～12 铁 / 人日

---

# 9. 金属

铁必须经过加工。

例如：

```text
铁 × 2
→ 金属 × 1
```

高级炉可提高：

```text
铁 × 2
→ 金属 × 1.2
```

所有涉及小数的生产，应以内部整数最小单位处理。

---

# 10. 燃料

用途：

```text
发电
车辆
高级生产
部分探索
```

燃料是中后期的重要战略资源。

基础燃油发电机：

> 5 燃料 → 20 电力

强化后：

> 5 燃料 → 25～30 电力

---

# 11. 零件

```text
工作台
工业工坊

探索
贸易
```

基础：

```text
2 金属
→
1 零件
```

主要用于：

```text
维修
高级建筑
机器

```

---

# 12. 药品

药品不应该过度产出。

主要来源：

```text
医疗室
探索
贸易
派系奖励
```

基础医疗：

```text
药品 × 1
→ 治疗 20～30 生命
```

高级医疗设施：

```text
药品 × 1
→ 治疗 35～45
```

---

# 13. 电子元件

来源：

```text
科研
拆解
旧研究站
高级贸易
```

属于稀缺工业资源。

用途：

```text
自动化
研究设备
高级能源
方舟
```

原则：

> 不能大量稳定生产。

这样它才具有探索价值。

---

# 14. 稀有矿物

极少量出现。

主要作用：

```text
高级科技
传奇建筑
方舟
部分传奇遗物
```

常规基地不应该能够无限量生产。

# 16. 资源容量

初始：

```text
仓库容量：100
```

升级：

```text
仓库 Lv2：250
仓库 Lv3：500
大型仓储：1000
```

特殊高价值资源可以拥有独立容量。

---

# 17. 资源价格

贸易价值必须统一使用内部基准价值。

建议：

```text
食物：1
水：1
木材：1
石材：1
铁：2
金属：4
燃料：4
零件：8
药品：10
电子元件：20
稀有矿物：30
```

这些不是玩家直接看到的金币价格。

只是：

> 用于交易、奖励和随机事件的统一价值参考。

---

# 18. 资源危机阈值

以未来 3 天消耗计算：

```text
> 5 天：稳定
3～5 天：正常
2～3 天：警戒
1～2 天：危险
< 1 天：危机
0：断供
```

---

# 19. 资源不会因为低于 0 而无限欠账

所有资源默认：

> 最低 0。

不足部分转化为对应后果。

例如：

```text
食物不足
→ 饥饿

水不足
→ 健康下降

燃料不足
→ 发电停止

零件不足
→ 建筑无法维修
```

不能允许：

> -9999 食物。

---

# 20. 数值平衡原则

V1 中，一个正常玩家在不刻意极限优化时：

```text
Day 1～5：
经常缺少一种资源

Day 6～15：
能够维持基本稳定

Day 16～30：
开始建立库存

Day 31～45：
库存与消耗同时扩大

Day 46～60：
库存成为终局战略资源
```

---

# 21. 玩家永远至少应该存在解决方案

资源危机出现时，系统至少提供 2～3 种解决思路：

```text
增加生产
减少消耗
探索获取
交易购买
牺牲其他系统
使用肉鸽能力
```

禁止出现：

> 唯一解不存在导致必死。

除非该事件本身就是明确的高风险赌局。

---

# 09 完成标准

Agent 实现时必须：

* 所有资源数据独立配置。
* 支持最大值、当前值、基础消耗、生产来源。
* 支持资源转换。
* 支持未来 N 天预测。
* 支持警告状态。
* 支持资源不足事件。
* 支持存档。
