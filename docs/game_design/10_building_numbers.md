# 《最后避难所》建筑数值规格

# 1. 建筑设计原则

建筑必须满足：

```text
建造成本
+
维护成本
+
生产收益
+
能源需求
+
升级收益
```

禁止所有建筑都只有：

> 建造后永久 +X。

# 16. 方舟核心

```text

```

---

# 17. 建筑升级统一规则

升级通常：

```text
原建筑成本的：
50%～80%
```

升级应主要提供：

```text
产能
容量
效率
稳定性
特殊功能
```

而不是单纯：

> +100% 所有数值。

---

# 18. 建筑故障

以下建筑拥有故障概率：

```text
发电机
自动化中心
高级工坊
研究所
净水站
```

故障条件：

```text
耐久 < 30%
```

效果：

```text
效率下降
或者
完全停止
```

---

# 19. 建筑维护

维护属于长期经营成本。

建议：

```text
普通建筑：
每 10 天维护

工业建筑：
每 5 天维护

高级建筑：
每 3～5 天维护
```

玩家可以选择：

> 暂不维护。

但故障概率提高。

# 21. 建筑平衡原则

前期：

> 少数建筑决定能否生存。

中期：

> 建筑形成生产链。

后期：

> 建筑形成流派。

终局：

> 建筑转化为终局资源。
