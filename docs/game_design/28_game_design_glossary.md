术语使用规则

后续所有设计文档、代码、Agent 提示词都应该优先使用本文件中的固定术语。

例如统一使用：

“遗物”

而不要在不同文档分别写：

神器
装备核心
特殊被动
传奇物品

除非这些实际上是不同系统。
