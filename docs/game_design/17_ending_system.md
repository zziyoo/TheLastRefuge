《最后避难所》终局与结局系统
1. 设计目标

Day 60 不是简单：

“检查某个数值是否达标”。

终局应该总结整个 60 天。

2. 终局进入

Day 48：

开启终局倒计时。

Day 56：

进入终局准备。

Day 60：

结局判定。

3. 终局核心指标
arkCompletion
population
health
foodReserve
waterReserve
energy
factionRelations
characterStability
worldStability
constructionTags
4. 默认目标：方舟

方舟分三阶段：

核心
能源
生命维持
导航

每阶段需要：

资源
时间
建筑
科技
5. 结局类型

至少第一版：

Ending_01 全员撤离
Ending_02 部分撤离
Ending_03 永久基地
Ending_04 派系接管
Ending_05 基地毁灭
Ending_06 隐藏结局
6. 全员撤离

基础条件：

方舟完成
方舟容量 = 存活人口
能源足够
核心未损坏
7. 部分撤离
方舟完成
但容量  存活人口

最终按照：

角色优先级
关系
职位
玩家选择

决定谁离开。

8. 永久基地

满足：

不完成方舟
+
生态自治相关构筑
+
足够基础设施
+
人口稳定
+
终局灾难成功抵御
9. 派系接管

满足：

某派系声望极高
+
玩家接受终局协议

基地并入该派系。

10. 基地毁灭

触发：

核心系统损坏
+
关键资源归零

或：

人口全部死亡
11. 隐藏结局

隐藏结局应使用多条件组合。

例：

完成古代数据库
+
完成空间站事件链
+
获得异常信号
+
没有加入军方
+
最终拥有能源核心

解锁：

“发现真实世界”。

12. 结局评分不是排名

结局展示：

生存天数
存活人数
主要流派
派系关系
科技
遗物
重大事件

不使用简单“分数评价玩家”。

13. 终局报告

示例：

12

工业自动化

太阳风暴

━━━━━━━━━━━━━━━━━━
14. 结局条件必须数据化

不要把所有结局判断写在一个巨大：

EndingManager.cs

应该：

EndingDefinition
{
    id,
    priority,
    conditions,
    result,
    rewards,
    unlocks
}
15. 结局优先级

隐藏结局优先检查。

然后：

特殊结局
→ 正常结局
→ 失败结局

避免符合多个条件时结果不可预测。
