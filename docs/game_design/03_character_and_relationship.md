# 《最后避难所》角色、性格与关系系统

# 1. 角色定位

角色不是资源单位。

每名角色都应该具备：

```text
能力
性格
经历
需求
关系
成长
故事
```

---

# 2. 基础属性

```text
生命
体力
饥饿
压力
健康
```

---

# 3. 能力属性

建议第一版：

```text
农业
采集
工程
研究
医疗
探索
战斗
```

范围：

> 1～10

---

# 4. 职业

职业只是角色初始定位。

例如：

```text
农民
矿工
工程师
医生
研究员
猎人
士兵
商人
```

职业不限制角色做其他工作。

---

# 5. 特性

特性分为：

## 正面

```text
勤奋
乐观
坚韧
聪明
节俭
领导者
```

## 中性

```text
夜猫子
独处需求
冒险家
收藏家
```

## 负面

```text
胆小
贪食
悲观
懒惰
失眠
易怒
```

特性应该影响玩法，而不仅仅是描述。

---

# 6. 特性成长

角色在特定经历后可能获得新特性。

例如：

```text
连续 5 次成功治疗
→ 医疗专家

成功完成高危探索
→ 老练探险家

经历队友死亡
→ 坚韧 / 创伤

完成大型工程
→ 工程大师
```

---

# 7. 人物需求

人物除了生命，还应该拥有：

```text
食物需求
睡眠需求
安全需求
娱乐需求
社交需求
```

满足程度影响压力。

---

# 8. 压力系统

建议采用：

```text
0～29   正常
30～49  紧张
50～69  压力
70～89  高压
90～100 崩溃风险
```

压力来源：

```text
饥饿
疾病
死亡
争吵
危险探索
睡眠不足
糟糕环境
长期工作
```

降低压力：

```text
休息
娱乐
社交
好食物
胜利
安全住所
完成个人目标
```

---

# 9. 人际关系

任意两名角色之间拥有关系值。

建议：

```text
-100 ～ +100
```

阶段：

```text
敌视
厌恶
陌生
普通
熟悉
朋友
亲密
```

---

# 10. 关系变化

关系受以下因素影响：

```text
共同工作
共同探索
互相救助
争吵
利益冲突
资源分配
共同经历重大事件
```

---

# 11. 关系事件

例如：

```text
王与陈争夺房间。

① 让王搬走
② 让陈搬走
③ 扩建住房
④ 不干涉
```

结果不仅影响当天。

可能影响：

```text
关系值
压力
工作效率
忠诚
未来事件
```

---

# 12. 关系对经营的影响

例如：

```text
朋友：
共同工作时效率 +5%

亲密：
压力增长降低

敌视：
共同工作时效率 -10%

敌对：
可能产生冲突事件
```

---

# 13. 角色死亡

角色死亡必须有长期影响。

例如：

```text
好友死亡
→ 压力 +25

领导者死亡
→ 全体信心下降

医生死亡
→ 医疗能力下降
```

死亡不是简单：

> 人口 -1。

---

# 14. 招募

新角色来自：

```text
事件
探索
商人
派系
救援
随机访客
```

每个角色应该拥有：

```text
随机职业
随机属性
随机特性
随机过去
```

这使每局人物池不同。

---

# 15. 人物故事

少量角色可以拥有个人任务。

例如：

```text
“找到我的妹妹”

“修复旧研究站”

“找到失踪队伍”

“回到故乡”
```

完成后可能获得：

```text
新特性
特殊装备
派系关系
肉鸽奖励
隐藏结局
```
