2. 普通强化

一次选择：

三选一。

普通强化主要改变一个系统。

示例：

高效农业
农业产量 +15%
节能设备
建筑能源消耗 -10%
快速维修
维修时间 -30%
野外经验
探索资源 +15%
节约用水
水消耗 -10%
3. 稀有强化

改变两个系统。

例如：

农业机械化
农业产量 +20%
农业需要人数 -1
但电力消耗 +10%
医疗改革
治疗效率 +30%
疾病概率 -10%
药品消耗 +10%
4. 史诗强化

改变玩法。

例如：

无人农场

获得：

农田不再需要永久配置人员。

但是：

每日额外消耗电力。

19. 肉鸽选择保护

连续 3 次没有出现当前主要流派相关内容：

提高相关内容出现概率。

连续 5 次：

至少出现一项与当前核心需求相关的选项。

但不能保证玩家直接得到最优选择。
