# 《最后避难所》每日循环与时间系统

## 1. 设计目标

游戏单局 60 天。

玩家现实中每天建议游玩：

> 1～2 小时。

游戏不应该通过强制实时倒计时制造时长。

主要时间来自：

> 决策、管理、事件阅读、探索选择和基地发展。

---

# 2. 一个游戏日结构

每一天分为：

```text
清晨
上午
中午
下午
傍晚
夜晚
```

共 6 个主要时间段。

---

# 3. 清晨阶段

系统自动执行：

```text
天气更新
环境更新
资源库存更新
人物睡眠恢复
疾病检查
建筑状态检查
```

然后向玩家显示：

```text
第 27 天

天气：
暴雨

基地警报：
食物预计 4 天后不足

人员：
王：疲劳
李：压力较高

昨日事件：
矿洞事故
```

玩家查看信息后决定当天策略。

---

# 4. 上午阶段

玩家进行主要基地操作：

```text
分配人员
调整优先级
建造
生产
研究
维修
```

这里不要求每个时间段都点击大量按钮。

已经自动化的工作应该自动执行。

---

# 5. 中午阶段

主要处理主动活动：

```text
探索
交易
招募
派系任务
重要人物互动
```

一次探索可以跨越多个时间段。

---

# 6. 下午阶段

主要用于：

```text
继续生产
研究
维修
建筑
治疗
人物活动
```

如果发生事件，则暂停自动模拟，进入事件界面。

---

# 7. 傍晚阶段

进行一天的经营结算前检查：

```text
仓库
食物
水
电力
燃料
人员健康
人员压力
建筑损坏
探索队状态
```

玩家可以进行最后调整。

---

# 8. 夜晚阶段

系统执行：

```text
食物消耗
水消耗
能源消耗
人员休息
疾病判定
关系变化
随机夜间事件
```

然后进入：

> “第 X 天总结”。

---

# 9. 一天总结

必须生成可阅读的日志。

示例：

```text
第 27 天结束

资源：
食物 +12
水 -8
木材 -4
金属 +7

人员：
王：健康 -5
李：压力 +6
陈：获得“坚韧”

建筑：
农场产出增加
发电机损坏 15%

事件：
发现废弃研究站

关系：
王 ↔ 陈 信任 +3
```

玩家点击：

> 【进入第 28 天】

---

# 10. 时间消耗规则

主动行为具有时间成本。

例如：

| 行为   |  时间 |
| ---- | --: |
| 采集   |   1 |
| 短途探索 |   2 |
| 长途探索 | 4～8 |
| 研究   |   1 |
| 建造   | 1～4 |
| 修理   | 1～3 |
| 交易   |   1 |
| 治疗   | 1～3 |

时间成本不是绝对值。

科技、角色能力、遗物和建筑都可以改变时间消耗。

---

# 11. 自动化原则

游戏后期必须降低重复操作。

例如：

### 前期

玩家每天手动：

```text
王 → 采矿
陈 → 农业
李 → 研究
```

### 后期

可以设置：

```text
采矿：
自动维持铁 ≥ 30

农业：
自动维持食物 ≥ 80

研究：
自动分配最高研究优先级人员
```

因此后期玩家操作量不能无限增长。

---

# 12. 每日内容量

一个普通游戏日建议包含：

```text
1 个基地管理决策
+
1 个主动活动
+
1 个随机事件
+
1 次资源结算
+
0～2 个次要事件
```

重大日可增加到：

```text
2～3 个关键事件
+
1 个重大决策
```

---

# 13. 防止重复操作

以下内容应该逐渐自动化：

```text
普通资源采集
普通农业
普通生产
基础维修
人员工作分配
库存转移
```

玩家长期负责的是：

```text
战略
人员
构筑
风险
派系
探索
终局
```

---

# 14. 离线继续

游戏可以在任意时刻保存。

不要求后台挂机。

原则：

> 玩家离开游戏不会错过实时事件。

重新进入时，继续当前游戏时间。
